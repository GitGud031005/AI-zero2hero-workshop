# AI-zero2hero-workshop

Materials and practice notebooks from the AI Zero to Hero workshop.

- `Notebooks/` – original notebooks, written for Google Colab
- `Data/` – datasets used by the notebooks
- `Notebooks_local/` – copies adapted to run locally with Jupyter (own `Data/` copy, no Google Drive)

## Run locally

```bash
pip install notebook matplotlib seaborn scikit-learn scipy plotly
cd Notebooks_local
jupyter notebook
```
